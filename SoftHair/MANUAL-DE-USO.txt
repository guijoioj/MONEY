================================================================================
                    1. INSTALAÇÃO E INICIALIZAÇÃO
================================================================================

1.1 REQUISITOS DO SISTEMA
--------------------------
- Node.js 18 ou superior
- Sistema Operacional: Windows 10+, Linux, macOS 10.15+
- Memória RAM: 4GB ou mais
- Espaço em disco: 500MB

1.2 INICIALIZAÇÃO RÁPIDA (1 CLIQUE)
-------------------------------------
WINDOWS:
  1. Clique duas vezes no arquivo "iniciar-sistema.bat"
  2. O sistema aguardará o backend (6s) e frontend (6s)
  3. O navegador será aberto automaticamente

LINUX:
  1. Dê permissão: chmod +x "Iniciar Sistema.sh"
  2. Clique duas vezes no arquivo

1.3 INICIALIZAÇÃO MANUAL (TERMINAL)
-----------------------------------

# Terminal 1 - Backend
cd backend
npm install (se primeira vez)
npm run dev

# Terminal 2 - Frontend
cd frontend
npm install (se primeira vez)
npm run dev

# Acesse: http://localhost:3000

1.4 URLs DO SISTEMA
--------------------
Frontend (Navegador):  http://localhost:3000
Backend (API):          http://localhost:3001

================================================================================
                        5. GESTÃO DE CLIENTES
================================================================================

5.1 CADASTRAR NOVO CLIENTE
-----------------------------
1. Clique em "Clientes" no menu
2. Clique no botão "+ Novo Cliente"
3. Preencha os campos:
   - Nome * (obrigatório)
   - Telefone * (obrigatório)
   - E-mail
   - CPF
   - Data de Nascimento
   - Endereço
   - Observações
4. Clique em "Salvar"

5.2 BUSCAR CLIENTES
---------------------
Use a caixa de busca para encontrar clientes por:
- Nome
- Telefone
- E-mail

5.3 EDITAR/EXCLUIR CLIENTE
-----------------------------
1. Na lista de clientes, clique no ícone de edição (lápis)
2. Ou clique no ícone de lixeira para excluir

5.4 PERFIL DO CLIENTE (HISTÓRICO)
-----------------------------------
Clique no ícone de usuário ao lado do nome para ver o perfil completo:

- ATENDIMENTOS: Total de atendimentos realizados
- COMPRAS: Total de compras de produtos
- GASTO EM SERVIÇOS: Valor total gasto em serviços
- GASTO EM PRODUTOS: Valor total gasto em produtos
- SERVIÇOS MAIS FREQUENTES: Ranking de serviços preferidos
  (atualizado automaticamente após fechamentos)
- PRODUTOS MAIS COMPRADOS: Ranking de produtos preferidos
  (atualizado automaticamente após fechamentos)
- PROFISSIONAIS PREFERIDOS: Profissionais mais atendidos
- ÚLTIMOS ATENDIMENTOS: Histórico recente com opção de estorno

5.5 ESTORNO DE FECHAMENTO NO PERFIL
-------------------------------------
No perfil do cliente, cada fechamento possui um botão para estornar.
O estorno:
- Reabre os itens fechados
- Registra o motivo do estorno
- Atualiza o histórico do cliente

================================================================================
                     8. GESTÃO DE PROFISSIONAIS
================================================================================

8.1 CADASTRAR NOVO PROFISSIONAL
----------------------------------
1. Clique em "Profissionais" no menu
2. Clique no botão "+ Novo Profissional"
3. Preencha os campos:
   - Nome *
   - Telefone *
   - E-mail
   - Especialidades (ex: "Auxiliar de Cabelo", "Assistente de Manicure")

Exemplos:
- "Auxiliar de Cabelo" - aparecerá como auxiliar
- "Assistente de Manicure" - aparecerá como auxiliar
- "Cabeleireiro Senior" - não aparecerá como auxiliar

================================================================================
                              9. AGENDA
================================================================================

9.1 VISÃO GERAL
----------------
A Agenda exibe visualmente os agendamentos em formato de grade, permitindo 
ver a ocupação de cada profissional ao longo do dia.

9.2 CÉLULAS E CORES
---------------------
| Tipo          | Cor    | Descrição                              |
|---------------|--------|----------------------------------------|
| Agendamento   | Amarelo| Agendamento criado                     |
| Confirmado    | Verde  | Cliente confirmou                       |
| Cancelado     | Vermelho| Agendamento cancelado                 |
| Atendimento   | Roxo   | Agendamento convertido em atendimento  |
| Auxiliar     | Teal   | Quando um profissional é auxiliar     |

9.3 CRIAR NOVO AGENDAMENTO
----------------------------
1. Clique em "Agenda" no menu
2. Selecione a data desejada usando o seletor de calendário
3. Clique no botão "+ Novo Agendamento" ou clique em uma célula vazia
4. Preencha os campos:
   - Cliente * (selecione na lista)
   - Serviço * (selecione na lista)
   - Profissional * (selecione na lista)
   - Auxiliar (opcional - apenas profissionais auxiliares)
   - Data e Hora *
   - Status (Agendado, Confirmado ou Cancelado)
   - Observações
5. Clique em "Salvar"

9.4 DROPDOWN DE AUXILIAR
-------------------------
O dropdown de auxiliares mostra apenas profissionais que possuem 
"auxiliar" ou "assistente" na especialidade.

Se nenhum profissional tiver essa especialidade, a lista ficará vazia.

9.5 EDITAR AGENDAMENTO
-----------------------
Clique em qualquer célula de agendamento para abrir o modal de edição:

- Células amarelas, verdes ou vermelhas: Abrem modal de edição
- Células roxas (atendimentos): Abrem modal de visualização
- Campos desabilitados: Quando visualizando, os campos são apenas leitura

9.6 CONVERTER PARA ATENDIMENTO
--------------------------------
1. Edite o agendamento desejado
2. Clique no botão "Converter p/ Atendimento"
3. Confirme a ação
4. O agendamento vira roxo na agenda
5. Você é redirecionado para a aba de Atendimentos
6. O modal de edição de atendimento é aberto automaticamente

9.7 CÉLULA DO AUXILIAR
------------------------
Quando um agendamento tem auxiliar:
- O profissional principal aparece na coluna correspondente
- O auxiliar aparece na coluna dele com cor teal
- Exibe: "Auxiliar: [nome do auxiliar]" e abaixo o nome do cliente

9.8 FILTROS
-------------
- Tipo: Todos, Profissionais ou Assistentes
- Profissionais: Selecione quais profissionais ver na grade
- Status: Todos, Agendado, Confirmado, Cancelado ou Convertido

================================================================================
                           10. ATENDIMENTOS
================================================================================

10.1 REGISTRAR NOVO ATENDIMENTO
----------------------------------
1. Clique em "Atendimentos" no menu
2. Clique no botão "+ Novo Atendimento"
3. Preencha os campos:
   - Profissional
   - Auxiliar (opcional - apenas profissionais auxiliares)
   - Cliente
   - Data
4. Adicione produtos usados (se houver)
5. Adicione serviços realizados

10.2 DROPDOWN DE AUXILIAR
---------------------------
Mostra apenas profissionais com "auxiliar" ou "assistente" na especialidade.

10.3 CONTROLE DE ESTOQUE
---------------------------
Ao registrar atendimento com produtos, o estoque é atualizado 
automaticamente.

10.4 FLUXO DE TRABALHO
------------------------
1. Registre o atendimento com produtos e serviços
2. Após finalizado, vá para "Fechamento"
3. Selecione o cliente e finalize o pagamento
4. O histórico é salvo automaticamente no perfil do cliente
5. Os serviços e produtos favoritos são atualizados

================================================================================
                             11. VENDAS
================================================================================

11.1 REGISTRAR NOVA VENDA
---------------------------
1. Clique em "Vendas" no menu
2. Clique em "+ Nova Venda"
3. Selecione cliente (opcional - ou "Consumidor Final")

11.2 ESTOQUE AUTOMÁTICO
-------------------------

11.3 FILTRAR VENDAS
---------------------
- Por data específica

================================================================================
                            12. FECHAMENTO
================================================================================

12.1 O QUE É O FECHAMENTO?
----------------------------
O Fechamento é onde você encerra as contas a receber de clientes, tanto 
de atendimentos quanto de vendas realizadas.

12.2 COMO FUNCIONA
--------------------
1. Registre atendimentos e vendas normalmente
2. Vá para a aba "Fechamento"
3. Busque por cliente ou profissional
4. O sistema lista todos os itens em aberto do cliente
5. Selecione o que deseja fechar (atendimentos e/ou vendas)
6. Escolha a forma de pagamento:
   - Dinheiro
   - PIX
   - Cartão de Crédito
   - Cartão de Débito
7. Aplique desconto se necessário
8. Clique em "Confirmar Fechamento"

12.3 REGRAS IMPORTANTES
------------------------
- Pode fechar apenas vendas (sem atendimento)
- Pode fechar apenas atendimentos (sem venda)
- Pode fechar ambos juntos
- O histórico é salvo no perfil do cliente automaticamente
- Serviços e produtos favoritos são atualizados no perfil

12.4 FILTROS
--------------
- Por cliente: digite o nome na busca
- Por profissional: selecione na lista

================================================================================
                          13. ADMINISTRATIVO
================================================================================

13.1 VISÃO GERAL
-----------------
A aba Administrativo oferece ferramentas completas para gestão financeira,
controle de caixas, comissões de profissionais, créditos e relatórios gerais.

13.2 CHECK OUT (CONTROLE DE CAIXAS)
-------------------------------------
Visualize e gerencie todos os fechamentos realizados:

1. Selecione a data desejada
2. Veja o resumo:
   - Total do Dia: Soma de todos os fechamentos
   - Fechamentos: Quantidade de contas fechadas
   - Em Atendimentos: Valor de serviços
   - Em Vendas: Valor de produtos

3. Tabela de fechamentos com:
   - Cliente
   - Data
   - Profissional
   - Valores de atendimentos e vendas
   - Total geral

4. ESTORNO DE FECHAMENTO:
   - Clique no botão X para estornar um fechamento
   - Informe o motivo do estorno (obrigatório)
   - Clique em "Confirmar Estorno"
   - O fechamento é movido para a aba "Estornos"

13.3 ABA ESTORNOS
-------------------
Visualize todos os fechamentos estornados:
- Lista de fechamentos com marcação de estorno
- Motivo do estorno registrado
- Data do estorno

13.4 FATURAMENTO
------------------
Relatórios de faturamento por período:

A) ANALÍTICO:
   Lista detalhada de todos os fechamentos no período.

B) POR PROFISSIONAL:
   Mostra o total faturado por cada profissional.

C) POR FORMA DE PAGAMENTO:
   Agrupa os fechamentos por forma de pagamento
   (dinheiro, PIX, cartão crédito, cartão débito).

D) CRÉDITOS NA CASA:
   Gerenciamento de créditos dados aos clientes.

   - Adicionar crédito: Clique em "+ Novo Crédito"
   - Selecione o cliente
   - Escolha "Crédito (+)" ou "Débito (-)"
   - Informe o valor e descrição
   - O saldo é atualizado automaticamente

13.5 COMISSÕES
----------------
Controle de comissões dos profissionais:

A) A PAGAR:
   - Lista de profissionais com valores a receber
   - Clique em "Pagar" para registrar o pagamento
   - O valor é movido para a aba "Pagas"

B) PAGAS:
   - Registro de pagamentos realizados
   - Clique em "Estornar" para devolver o valor

C) ESTORNO DE PAGAMENTO:
   - Informe o motivo do estorno
   - O valor retorna para "A Pagar"

D) EDITAR COMISSÕES:
   - Clique no botão de edição na lista de profissionais
   - Altere o percentual de comissão
   - Clique em "Salvar"

13.6 RELATÓRIOS GERAIS
------------------------

A) AGENDA/SERVIÇOS:
   Lista de agendamentos do dia com status.

B) ANIVERSARIANTES:
   Lista de clientes que fazem aniversário no mês atual.
   Útil para preparar campanhas de aniversário.

C) PROFISSIONAIS:
   Lista de todos os profissionais ativos com dados de contato
   e percentual de comissão.

D) ESTOQUE:
   Lista completa de produtos com:
   - Estoque atual
   - Estoque mínimo configurado
   - Preço de venda
   - Alerta visual para estoque baixo (vermelho)

E) TABELA DE PREÇOS:
   Lista de preços de serviços e produtos para consulta rápida.

                       15. BACKUP E RESTAURAÇÃO
================================================================================

15.1 CRIAR BACKUP LOCAL
-------------------------
1. Clique em "Backup" no menu
2. Clique em "Criar Novo Backup"
3. O arquivo JSON será salvo na pasta "backups"
4. O backup contém todos os dados do sistema

15.2 RESTAURAR BACKUP
------------------------
ATENÇÃO: Dados atuais serão substituídos!

1. Clique em "Backup" no menu
2. Localize o backup desejado na lista
3. Clique em "Restaurar"
4. CONFIRME a ação

15.3 SINCRONIZAR COM GOOGLE DRIVE
-----------------------------------
1. Clique em "Backup" no menu
2. Na seção "Google Drive", clique em "Autorizar Google Drive"
3. Faça login na sua conta Google
4. Copie o código de verificação
5. Cole no campo e clique em "Confirmar"
6. Após conectado, sincronize backups clicando no ícone de nuvem

15.4 EXPORTAR BACKUP PARA OUTRO COMPUTADOR
--------------------------------------------
1. Clique em "Backup"
2. Clique em "Download" no backup desejado
3. Copie o arquivo para o outro computador
4. No outro computador, restaure o backup

=================================================================================
                     18. PROGRAMA DE FIDELIDADE
=================================================================================

18.1 REGRAS DO PROGRAMA
------------------------
- 5% de crédito em compras acima de R$100
- Crédito pode ser usado como desconto em futuros atendimentos
- Saldo acumulado aparece no perfil da cliente

18.2 COMO FUNCIONA
--------------------
1. Cliente faz um fechamento acima de R$100
2. Sistema gera automaticamente 5% do valor como crédito
3. Crédito é registrado na conta da cliente
4. Em futuros fechamentos, a cliente pode usar o crédito

18.3 VISUALIZAR CRÉDITO
------------------------
No perfil da cliente (ícone de usuário):
- Card "Crédito" mostra o saldo disponível
- Exibe informação: "5% acima de R$100"

18.4 USAR CRÉDITO NO FECHAMENTO
-------------------------------
1. Abra o módulo Fechamento
2. Selecione a cliente
3. Se houver crédito disponível, aparecerá uma caixa amarela
4. Marque "Usar crédito como desconto"
5. O crédito será convertido em desconto no valor total
6. Clique em "Confirmar Fechamento"

IMPORTANTE: O crédito usado é debitado da conta da cliente
automaticamente após o fechamento.

=================================================================================
                          19. SOLUÇÃO DE PROBLEMAS
================================================================================

18.1 SISTEMA NÃO INICIA
-------------------------
1. Verifique se o Node.js está instalado:
   node --version

2. Verifique se as portas 3000 e 3001 estão livres:
   Linux: lsof -i :3000 -i :3001
   Windows: netstat -ano | findstr "3000 3001"

3. Tente reiniciar usando iniciar-sistema.bat

18.2 ERRO DE LOGIN
--------------------
1. Verifique se está usando o e-mail correto
2. Verifique se o CAPS LOCK está desligado
3. Use a função "Esqueceu a senha?" se necessário

18.3 BACKUP NÃO FUNCIONA
--------------------------
1. Verifique se a pasta "backups" existe
2. Verifique permissões de escrita
3. Verifique espaço em disco

18.4 SERVIÇOS/PRODUTOS NÃO APARECEM
--------------------------------------
1. Verifique se estão marcados como "Ativo"
2. Use os filtros para encontrar

18.5 ERRO AO FECHAR CONTA
---------------------------
1. Selecione pelo menos um atendimento OU uma venda
2. Não é necessário ter ambos

18.6 HISTÓRICO DO CLIENTE VAZIO
---------------------------------
O histórico é preenchido automaticamente ao realizar fechamentos.
Se estiver vazio, certifique-se de:
1. Ter realizado atendimentos ou vendas
2. Ter fechado a conta na aba Fechamento

18.7 SERVIÇOS/PRODUTOS FAVORITOS NÃO ATUALIZAM
-------------------------------------------------
Os favoritos são calculados automaticamente a partir dos fechamentos 
realizados. Quanto mais fechamentos, mais preciso o ranking.

18.8 DROPDOWN DE AUXILIARES VAZIO
-----------------------------------
Verifique se algum profissional possui "auxiliar" ou "assistente" 
na especialidade. Apenas esses profissionais aparecerão no dropdown.
