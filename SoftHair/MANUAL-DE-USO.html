1. Instalação e Inicialização

1.1 Requisitos do Sistema

  • Node.js 18 ou superior
  • Sistema Operacional: Windows 10+, Linux, macOS 10.15+
  • Memória RAM: 4GB ou mais
  • Espaço em disco: 500MB

1.2 Modos de Uso

O SoftHair pode ser usado de duas formas:

Modo Descrição Melhor para
App Desktop (Electron) Abre como aplicativo nativo, sem navegador Uso diário no computador do salão
Navegador (Web) Abre no browser via localhost:3000 Desenvolvimento, acesso remoto

1.3 Inicialização — App Desktop (Electron)

Plataforma Comando / Arquivo Como Usar
Linux (CachyOS, Ubuntu, etc.) npm start Execute no terminal dentro da pasta SoftHair
Windows npm start Execute no terminal dentro da pasta SoftHair
Funcionamento do Electron: O sistema inicia o backend automaticamente em segundo plano. A janela só abre após confirmar que o backend está pronto (health check). Não é necessário abrir nenhum navegador.

1.4 Inicialização — Modo Navegador (Web)

Plataforma Arquivo Como Usar
Linux iniciar-sistema.sh Execute no terminal: ./iniciar-sistema.sh
Windows iniciar-sistema.bat Clique 2x no arquivo
Acesse em: http://localhost:3000 após o script informar que o sistema está pronto.

1.5 Inicialização Manual (Terminal)

# Terminal 1 - Backend
cd backend
npm install
npm run dev

# Terminal 2 - Frontend  
cd frontend
npm install
npm run dev

# Acesse: http://localhost:3000

5. Gestão de Clientes

5.1 Cadastrar Novo Cliente

  1. Clique em "Clientes" no menu
  2. Clique no botão "+ Novo Cliente"
  3. Preencha os campos obrigatórios (*): Nome, Telefone
  4. Campos opcionais: E-mail, CPF, Data de Nascimento, Endereço, Observações
  5. Clique em "Salvar"

5.2 Buscar Clientes

Use a caixa de busca para encontrar clientes por nome, telefone ou e-mail.

5.3 Editar/Excluir Cliente

Na lista de clientes, use os ícones de edição (lápis) ou lixeira.

5.4 Perfil do Cliente (Histórico)

Clique no ícone de usuário ao lado do nome para ver o perfil completo:

  • Atendimentos: Total de atendimentos realizados
  • Compras: Total de compras de produtos
  • Gasto em Serviços: Valor total gasto em serviços
  • Gasto em Produtos: Valor total gasto em produtos
  • Serviços Mais Frequentes: Ranking de serviços preferidos (atualizado após fechamentos)
  • Produtos Mais Comprados: Ranking de produtos preferidos (atualizado após fechamentos)
  • Profissionais Preferidos: Profissionais mais atendidos
  • Últimos Atendimentos: Histórico recente com possibilidade de estorno
Serviços e Produtos Favoritos: São calculados automaticamente a partir dos fechamentos realizados. Quanto mais fechamentos, mais preciso o ranking.

5.5 Estorno de Fechamento no Perfil

No perfil do cliente, cada fechamento possui um botão para estornar (ícone de giro). O estorno:

  • Reabre os itens fechados
  • Registra o motivo do estorno
  • Atualiza o histórico do cliente

6. Gestão de Serviços

6.1 Cadastrar Novo Serviço

  1. Clique em "Serviços" no menu
  2. Clique no botão "+ Novo Serviço"
  3. Preencha os campos obrigatórios: Nome, Duração (minutos), Preço
  4. Campos opcionais: Descrição, Categoria
  5. Marque "Serviço Ativo" se aplicável
  6. Clique em "Salvar"

6.2 Categorias Sugeridas

  • Cabelo
  • Unhas
  • Estética
  • Maquiagem
  • Barba
  • Spa

6.3 Filtrar Serviços

Use o filtro de categoria para ver serviços específicos ou a busca por nome.

7. Gestão de Produtos

7.1 Cadastrar Novo Produto

  1. Clique em "Produtos" no menu
  2. Clique no botão "+ Novo Produto"
  3. Preencha os campos (Preço Venda é obrigatório)
  4. Campos: Nome, Descrição, Marca, Categoria, Preço Custo, Preço Venda, Estoque, Estoque Mínimo
  5. Marque "Produto Ativo" se aplicável
  6. Clique em "Salvar"

7.2 Alertas de Estoque

Quando o estoque atual for menor ou igual ao estoque mínimo, o sistema exibirá um alerta vermelho.

7.3 Filtrar Produtos

  • Filtro por categoria
  • Busca por nome, marca ou descrição
  • Botão "Estoque Baixo" para ver apenas produtos críticos

8. Gestão de Profissionais

8.1 Cadastrar Novo Profissional

  1. Clique em "Profissionais" no menu
  2. Clique no botão "+ Novo Profissional"
  3. Preencha os campos: Nome, Telefone, E-mail
  4. Campos opcionais: Especialidades (ex: "Auxiliar de Cabelo", "Assistente de Manicure")
  5. Marque "Profissional Ativo" se aplicável
  6. Clique em "Salvar"
Especialidades: Se o profissional tem "auxiliar" ou "assistente" na especialidade, ele aparecerá na lista de auxiliares na Agenda e nos Atendimentos.

8.2 Comissões

O percentual de comissão é configurado na aba Administrativo > Comissões > Editar Comissões.

9. Agenda

9.1 Visão Geral

A Agenda exibe visualmente os agendamentos em formato de grade, permitindo ver a ocupação de cada profissional ao longo do dia.

9.2 Células e Cores

TipoCorDescrição
AgendamentoAmareloAgendamento criado
ConfirmadoVerdeCliente confirmou
CanceladoVermelhoAgendamento cancelado
AtendimentoRoxoAgendamento convertido em atendimento
AuxiliarTealQuando um profissional é auxiliar no atendimento

9.3 Criar Novo Agendamento

  1. Clique em "Agenda" no menu
  2. Selecione a data desejada usando o seletor de calendário
  3. Clique no botão "+ Novo Agendamento" ou clique em uma célula vazia
  4. Preencha os campos:
    • Cliente * (selecione na lista)
    • Serviço * (selecione na lista)
    • Profissional * (selecione na lista)
    • Auxiliar (opcional - apenas profissionais com "auxiliar/assistente" na especialidade)
    • Data e Hora *
    • Status (Agendado, Confirmado ou Cancelado)
    • Observações
  5. Clique em "Salvar"

9.4 Dropdown de Auxiliar

O dropdown de auxiliares mostra apenas profissionais que possuem "auxiliar" ou "assistente" na especialidade. Se nenhum profissional tiver essa especialidade, a lista ficará vazia.

9.5 Editar Agendamento

Clique em qualquer célula de agendamento para abrir o modal de edição:

  • Células amarelas, verdes ou vermelhas: Abrem modal de edição de agendamento
  • Células roxas (atendimentos): Abrem modal de visualização do agendamento original
  • Campos desabilitados: Quando visualizando um atendimento convertido, os campos são apenas leitura

9.6 Converter para Atendimento

  1. Edite o agendamento desejado
  2. Clique no botão "Converter p/ Atendimento"
  3. Confirme a ação
  4. O agendamento vira roxo na agenda
  5. Você é redirecionado para a aba de Atendimentos
  6. O modal de edição de atendimento é aberto automaticamente

9.7 Célula do Auxiliar

Quando um agendamento tem auxiliar:

  • O profissional principal aparece na coluna correspondente
  • O auxiliar aparece na coluna dele com cor teal
  • Exibe: "Auxiliar: [nome do auxiliar]" e abaixo o nome do cliente

9.8 Filtros

  • Tipo: Todos, Profissionais ou Assistentes
  • Profissionais: Selecione quais profissionais ver na grade
  • Status: Todos, Agendado, Confirmado, Cancelado ou Convertido

10. Atendimentos

10.1 Registrar Novo Atendimento

  1. Clique em "Atendimentos" no menu
  2. Clique no botão "+ Novo Atendimento"
  3. Preencha os campos:
    • Profissional
    • Auxiliar (opcional)
    • Cliente
    • Data
  4. Adicione produtos usados (se houver)
  5. Adicione serviços realizados
  6. O sistema calcula os totais automaticamente
  7. Clique em "Salvar Atendimento"
Dropdown de Auxiliar: Mostra apenas profissionais com "auxiliar" ou "assistente" na especialidade.

10.2 Controle de Estoque

Ao registrar atendimento com produtos, o estoque é atualizado automaticamente.

10.3 Fluxo de Trabalho

  1. Registre o atendimento com produtos e serviços
  2. Após finalizado, vá para "Fechamento"
  3. Selecione o cliente e finalize o pagamento
  4. O histórico é salvo automaticamente no perfil do cliente
  5. Os serviços e produtos favoritos são atualizados

11. Vendas

11.1 Registrar Nova Venda

  1. Clique em "Vendas" no menu
  2. Clique em "+ Nova Venda"
  3. Selecione cliente (opcional - ou "Consumidor Final")
  4. Selecione vendedor (opcional)
  5. Escolha a data
  6. Adicione produtos/serviços clicando neles
  7. Ajuste quantidades se necessário
  8. Clique em "Finalizar Venda"
Nota: A forma de pagamento é definida no Fechamento, não na Venda.

11.2 Atualização Automática de Estoque

Ao registrar venda de produtos, o estoque é atualizado automaticamente.

11.3 Filtrar Vendas

  • Por data específica
  • Por período (data início e fim)

12. Fechamento

12.1 O que é o Fechamento?

O Fechamento é onde você encerra as contas a receber de clientes, tanto de atendimentos quanto de vendas realizadas.

12.2 Como Funciona

  1. Registre atendimentos e vendas normalmente
  2. Vá para a aba "Fechamento"
  3. Busque por cliente ou profissional
  4. O sistema lista todos os itens em aberto do cliente
  5. Selecione o que deseja fechar (atendimentos e/ou vendas)
  6. Escolha a forma de pagamento:
    • Dinheiro
    • PIX
    • Cartão de Crédito
    • Cartão de Débito
  7. Aplique desconto se necessário
  8. Clique em "Confirmar Fechamento"

12.3 Regras Importantes

  • Pode fechar apenas vendas (sem atendimento)
  • Pode fechar apenas atendimentos (sem venda)
  • Pode fechar ambos juntos
  • O histórico é salvo no perfil do cliente automaticamente
  • Serviços e produtos favoritos são atualizados no perfil

12.4 Filtros

  • Por cliente: digite o nome na busca
  • Por profissional: selecione na lista

13. Administrativo

A aba Administrativo oferece ferramentas completas para gestão financeira, controle de caixas, comissões de profissionais, créditos e relatórios gerais.

13.1 Check Out (Controle de Caixas)

Gerencie todos os fechamentos realizados:

  • Selecione a data desejada
  • Veja o resumo: Total do Dia, Fechamentos, Atendimentos, Vendas
  • Tabela com cliente, data, profissional, valores e total
  • Estorno: Clique no botão X para estornar um fechamento

Estorno de Fechamento

  • Informe o motivo do estorno (obrigatório)
  • Clique em "Confirmar Estorno"
  • O fechamento é movido para a aba "Estornos"

13.2 Aba Estornos

Visualize todos os fechamentos estornados:

  • Lista de fechamentos com marcação de estorno
  • Motivo do estorno registrado
  • Data do estorno

13.3 Faturamento

Relatórios de faturamento por período:

  • Analítico: Lista detalhada de fechamentos
  • Por Profissional: Total faturado por profissional
  • Por Forma de Pagamento: Agrupado por PIX, dinheiro, cartão
  • Créditos na Casa: Gerenciamento de créditos dados aos clientes

Créditos na Casa

  • Clique em "+ Novo Crédito" para adicionar
  • Selecione o cliente
  • Escolha "Crédito (+)" ou "Débito (-)"
  • Informe o valor e descrição
  • O saldo é atualizado automaticamente

13.4 Comissões

Controle de comissões dos profissionais:

A Pagar

  • Lista de profissionais com valores a receber
  • Clique em "Pagar" para registrar o pagamento
  • O valor é movido para a aba "Pagas"

Pagas

  • Registro de pagamentos realizados
  • Clique em "Estornar" para devolver o valor

Estorno de Pagamento

  • Informe o motivo do estorno
  • O valor retorna para "A Pagar"

Editar Comissões

  • Clique no botão de edição na lista de profissionais
  • Altere o percentual de comissão
  • Clique em "Salvar"

13.5 Relatórios Gerais

  • Agenda/Serviços: Lista de agendamentos do dia
  • Aniversariantes: Clientes que fazem aniversário no mês
  • Profissionais: Lista com dados de contato e comissão
  • Estoque: Produtos com alerta de estoque baixo
  • Tabela de Preços: Consulta rápida de preços

18. Programa de Fidelidade

18.1 Regras do Programa

  • 5% de crédito em compras acima de R$100
  • Crédito pode ser usado como desconto em futuros atendimentos
  • Saldo acumulado aparece no perfil da cliente

18.2 Como Funciona

  1. Cliente faz um fechamento acima de R$100
  2. Sistema gera automaticamente 5% do valor como crédito
  3. Crédito é registrado na conta da cliente
  4. Em futuros fechamentos, a cliente pode usar o crédito como desconto

18.3 Visualizar Crédito

No perfil da cliente (ícone de usuário):

  • Card "Crédito" mostra o saldo disponível
  • Exibe informação: "5% acima de R$100"

18.4 Usar Crédito no Fechamento

  1. Abra o módulo Fechamento
  2. Selecione a cliente
  3. Se houver crédito disponível, aparecerá uma caixa amarela
  4. Marque "Usar crédito como desconto"
  5. O crédito será convertido em desconto no valor total
  6. Clique em "Confirmar Fechamento"
Importante: O crédito usado édebitado da conta da cliente automaticamente após o fechamento.

19.4 Banco de Dados no Electron

Quando o app é aberto via Electron, o banco de dados é armazenado na pasta de configuração do usuário:

Atenção: O banco de dados do Electron fica em um caminho diferente do banco usado quando o sistema é iniciado manualmente (modo terminal/navegador sem definir SOFTHAIR_ROOT_DIR). Certifique-se de usar sempre o mesmo modo de inicialização para garantir que os dados sejam os mesmos.

20. Solução de Problemas

Problema Solução
Sistema não inicia Verifique Node.js instalado e portas livres (3000, 3001)
Erro de login Verifique e-mail/senha, use recuperação se necessário
Backup não funciona Verifique permissões da pasta backups
Dados não aparecem Verifique se estão marcados como "Ativo"
Erro ao fechar conta Selecione pelo menos um atendimento ou venda
Histórico do cliente vazio Realize fechamentos para que o histórico seja registrado

Dropdown de auxiliares vazio Nenhum profissional tem "auxiliar" ou "assistente" na especialidade
Tela branca ao abrir o Electron Rebuild do frontend necessário: execute npm run build:frontend na pasta SoftHair
Login não redireciona (fica na tela de login) Certifique-se de abrir via npm start (Electron) ou iniciar-sistema.sh. Se o problema persistir, faça o rebuild do frontend.
Janela do Electron abre mas não carrega dados O backend ainda não estava pronto. O sistema aguarda automaticamente, mas em computadores lentos pode ser necessário aguardar alguns segundos antes de fazer login.
Electron não encontra o Node.js Verifique se o Node.js está instalado e acessível no PATH do sistema. Execute node --version no terminal para confirmar.
Dados do Electron não aparecem no navegador (ou vice-versa) Electron e o modo navegador usam bancos de dados em caminhos diferentes se SOFTHAIR_ROOT_DIR não for definido. Use sempre o mesmo modo de inicialização ou defina SOFTHAIR_ROOT_DIR no backend/.env.
Admin padrão não existe / não consegue fazer login O sistema cria o admin automaticamente na primeira execução. Se o banco foi criado sem o admin, reinicie o sistema — ele detectará a ausência e criará o usuário / automaticamente.
