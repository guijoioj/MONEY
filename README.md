## 📌 Sobre o Projeto
O **SoftHair** é uma aplicação completa (SaaS) desenvolvida para digitalizar e automatizar a gestão de horários e clientes do salão *Paula Pastre Professionals*. 

O objetivo arquitetural do projeto foi criar uma solução de alta disponibilidade na nuvem que resolvesse um problema real de logística de atendimento, substituindo o controle manual por um sistema relacional robusto.

## 🚀 Principais Funcionalidades
* **Agendamento Inteligente:** Controle de horários para evitar conflitos na agenda das profissionais.
* **Gestão de Clientes:** Cadastro e acompanhamento do histórico de serviços realizados.
* **Painel Administrativo:** Visão geral do fluxo de caixa e ocupação do salão.

## 🧠 Engenharia Assistida por IA (AI-Assisted Development)
Um dos grandes diferenciais técnicos deste projeto foi a utilização do **Claude Code** no fluxo de desenvolvimento. Atuei coordenando a Inteligência Artificial para:
1. **Acelerar o *boilerplate*:** Geração rápida da estrutura de componentes e serviços.
2. **Troubleshooting Avançado:** Depuração de erros de integração entre o front-end e o Supabase.
3. **Foco em Arquitetura:** Ao delegar a digitação de código repetitivo para a IA, pude focar inteiramente na modelagem do banco de dados, nas regras de negócio e na engenharia do prompt para garantir um código limpo e escalável.

## ⚙️ Arquitetura e Stack Tecnológica
A infraestrutura do SoftHair foi desenhada para ser escalável, utilizando ferramentas modernas de nuvem:

* **Backend / BaaS:** Supabase (SOFTHAIR-SERVER) gerenciando autenticação e rotas.
* **Banco de Dados:** PostgreSQL para garantir a integridade relacional entre Clientes, Serviços e Agendamentos (DB-SOFTHAIR).
* **Hospedagem e CI/CD:** Deploy automatizado na nuvem através do **Render**.
